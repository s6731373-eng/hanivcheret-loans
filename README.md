# דשבורד הלוואות - הנבחרת

מדריך התקנה שלב-אחר-שלב. יש שני חלקים: (1) הגדרת "השרת" ב-Google Sheets, (2) פרסום דף האינטרנט ב-GitHub Pages.

---

## חלק 1: הגדרת הגיליון והשרת (Google Apps Script)

1. פתחו [sheets.google.com](https://sheets.google.com) וצרו גיליון חדש. אפשר לקרוא לו "הלוואות החברה".
2. בתפריט העליון: **תוספים (Extensions) ← Apps Script**.
3. יימחק הקוד שכבר שם (`function myFunction()...`), ובמקומו יש להדביק את כל התוכן של הקובץ `Code.gs` המצורף.
4. ללחוץ על סמל השמירה (💾).
5. ללחוץ על **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
   - ליד "Select type" ללחוץ על גלגל השיניים ולבחור **Web app**.
   - **Execute as:** Me (החשבון שלכם)
   - **Who has access:** Anyone (כל מי שיש לו את הקישור)
   - ללחוץ **Deploy**.
6. בפעם הראשונה Google יבקש הרשאה - ללחוץ **Authorize access**, לבחור את חשבון Google שלכם, וללחוץ **Advanced ← Go to (שם הפרויקט) (unsafe)** ואז **Allow**. זה תקין - זה סקריפט שכתבתם בעצמכם.
7. תופיע כתובת שנראית כך: `https://script.google.com/macros/s/AKfycb.../exec` - **להעתיק אותה**, זו כתובת ה-API.

> הערה: בכל פעם שמעדכנים את הקוד ב-Apps Script בעתיד, צריך לבצע **Deploy ← Manage deployments ← עריכה (✎) ← Version: New version ← Deploy** כדי שהשינויים ייכנסו לתוקף.

הגיליון ייצור לבד שורת כותרות בשם "הלוואות" בפעם הראשונה שתטענו את הדף.

### הגדרת טוקן גישה (חשוב!)

מכיוון שהדשבורד יתפרסם ב-repo **ציבורי**, כל מי שישיג את כתובת ה-Web App (מה-API_URL) יוכל לקרוא ולערוך את הנתונים - אלא אם מגדירים טוקן סודי:

1. ב-Apps Script: **Project Settings** (⚙️ בתפריט השמאלי) ← לגלול עד **Script Properties** ← **Add script property**.
2. Property: `API_TOKEN`, Value: מחרוזת אקראית וארוכה (למשל 32 תווים אקראיים - אפשר להיעזר במחולל סיסמאות).
3. שמירה.
4. בקובץ `index.html` המקומי (**לפני** ההעלאה ל-GitHub, או אחרי - ראו אזהרה למטה) לאתר את המשתנה `API_TOKEN` ולהדביק שם את **אותה** מחרוזת בדיוק.

⚠️ **חשוב להבין את המגבלה**: מכיוון שזהו דף סטטי בלבד (בלי שרת משלכם), הדפדפן חייב לשלוח את הטוקן כדי להתאמת - ולכן הטוקן **יופיע בקוד המקור הפומבי** של הדף בדיוק כמו ה-API_URL עצמו (כל מי שיפתח את הדף ויבחר "הצג מקור" יראה אותו). הטוקן **לא** מגן מפני מישהו שבאמת פותח את הדשבורד וקורא את הקוד - הוא רק חוסם רובוטים/סורקים אוטומטיים שמחפשים כתובות Apps Script פתוחות ברשת בלי לטעון את הדף עצמו. ההגנה האמיתית היחידה היא לא להפיץ את כתובת הדשבורד לאף אחד שלא צריך לגשת אליה, ולזכור שמי שכן מגיע לדף יכול תיאורטית לגשת גם ל-API ישירות. אם רוצים הגנה אמיתית (כניסה עם סיסמה/חשבון גוגל), צריך שכבת שרת נוספת - זה מעבר למה שדף סטטי יכול לספק.

## חלק 2: פרסום הדף באינטרנט (GitHub Pages)

1. פתחו את הקובץ `index.html` בכל עורך טקסט (גם Notepad מספיק).
2. חפשו את השורה:
   ```js
   const API_URL = ''; // <-- להדביק כאן את כתובת ה-Web App
   ```
   והדביקו בין הגרשיים את הכתובת שהעתקתם בשלב 7 למעלה. לדוגמה:
   ```js
   const API_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
   ```
   לשמור את הקובץ.
3. ב-GitHub: צרו repository חדש (למשל `hanivcheret-loans`).
4. העלו אליו את הקובץ `index.html` (Add file ← Upload files).
5. בהגדרות ה-repository: **Settings ← Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main** / תיקייה **/(root)**
   - Save.
6. אחרי דקה-שתיים הדשבורד יהיה זמין בכתובת שתופיע שם, בדרך כלל:
   `https://<שם-המשתמש-שלכם>.github.io/hanivcheret-loans/`

## איך זה עובד

- **הזנת הלוואה חדשה** - לוחצים "הלוואה חדשה", ממלאים בנק, סכום, ריבית שנתית, תשלום חודשי, יום תשלום בחודש, ותאריך תחילה. הנתונים נשמרים ישירות בגיליון ה-Google Sheets.
- **חישוב היתרה** - כברירת מחדל היתרה **מחושבת אוטומטית** כל פעם שפותחים את הדף, לפי נוסחת לוח סילוקין רגיל (קרן + ריבית), על בסיס תאריך התחילה ומספר התשלומים שכבר היו אמורים לקרות עד היום.
- **תיקון ידני** - אם היתרה בפועל שונה (למשל פרעון מוקדם, או שהריבית בבנק השתנתה), אפשר לפתוח את ההלוואה לעריכה ולמלא בתיבה "יתרה מעודכנת ידנית" את הסכום הנכון ואת התאריך שבו הוא נכון. מאותה נקודה החישוב האוטומטי ימשיך הלאה, עד לתיקון הבא.
- **תשלומים קרובים** - בראש הדף מופיעה רשימה של כל התשלומים הצפויים ב-7 הימים הקרובים.
- **סטטוס** - סמנו הלוואה כ"סגורה" כשהיא נפרעת במלואה, כדי שלא תיכלל בסכומים הכוללים.
- הדף מותאם למובייל - הטבלה הופכת לכרטיסים כשפותחים אותו בטלפון.
